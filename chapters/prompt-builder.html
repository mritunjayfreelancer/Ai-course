                    Prompt actually strong kab hota hai?
                


                

                    Good prompting ka simple mental model yaad rakho.
                


            



            


                


                    

                        01
                    


                    

                        Goal clear karo
                    


                    

                        “Mujhe kuch batao” ke badle exact result batao.
                        AI ko destination pata hona chahiye.
                    


                



                


                    

                        02
                    


                    

                        Context do
                    


                    

                        Aap beginner ho ya expert, audience kaun hai,
                        problem kya hai — relevant background share karo.
                    


                



                


                    

                        03
                    


                    

                        Task define karo
                    


                    

                        AI se actual me kya karwana hai,
                        usko action ke form me clearly likho.
                    


                



                


                    

                        04
                    


                    

                        Boundaries set karo
                    


                    

                        Length, difficulty, things to avoid,
                        required details aur other constraints define karo.
                    


                



                


                    

                        05
                    


                    

                        Output design karo
                    


                    

                        AI ko batao answer kis format me useful rahega:
                        table, steps, checklist, tutorial ya report.
                    


                



                


                    

                        06
                    


                    

                        Quality check lagao
                    


                    

                        Final answer ko desired result ke against verify
                        karne ke instructions do.
                    


                


            


        



        

        


            


                

                    Real-world prompt thinking
                


                

                    Prompt ko command ki tarah nahi, clear briefing ki tarah socho.
                


            



            


                


                    
                        Study
                    

                    

                        Weak → Better
                    


                    

                        “Photosynthesis samjhao” se better hai:
                        level, purpose, examples aur expected explanation style
                        define karna.
                    


                



                


                    
                        Coding
                    

                    

                        Problem → Context → Fix
                    


                    

                        Sirf “code fix karo” ke badle code ka purpose,
                        error, expected behaviour aur restrictions provide karo.
                    


                



                


                    
                        Research
                    

                    

                        Question → Evidence → Output
                    


                    

                        Research prompt me scope, comparison criteria,
                        uncertainty aur source-handling expectations useful hote hain.
                    


                



                


                    
                        Writing
                    

                    

                        Audience matters
                    


                    

                        Same topic ko student, customer aur technical reader
                        ke liye completely different way me likhna pad sakta hai.
                    


                



                


                    
                        Planning
                    

                    

                        Outcome first
                    


                    

                        Plan banwate waqt available time, resources,
                        priorities aur practical limitations include karo.
                    


                



                


                    
                        Work
                    

                    

                        Define success
                    


                    

                        “Professional bana do” vague hai.
                        “Clear, concise, respectful and action-oriented” much better hai.
